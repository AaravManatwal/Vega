Phone se APK kaise banayein

  1. GitHub account aur naya repo
    Phone ke browser me github.com par login, New repository banaiye (Private rakhna theek hai).
  2. Zip ke andar ki files upload kijiye
    Zip ko pehle phone me extract kijiye (Files app). Repo me Add file → Upload files se saari files aur folders daliye. .github folder zaroor jaana chahiye, kyunki build usi me hai.
  3. Actions chalne dijiye
    Repo ke Actions tab me "Vega CI/CD Pipeline" apne aap chalegi. Teen kaam hote hain: web tests, Flutter tests, aur debug APK.
  4. APK download kijiye
    Run poora hone par us run ke neeche Artifacts → vega-debug-apk dabaiye. Zip aayegi, usme app-debug.apk hai.
  5. Install
    APK kholiye, "Install unknown apps" ki ijazat dijiye. Android 13 ya usse upar wale phone par hi chalega.

Agar koi step laal (fail) ho to us step ka log ka screenshot ya text mujhe bhej dijiye, main theek kar dunga. Dart code abhi tak kisi compiler par nahi chala, isliye pehle run me chhoti galtiyan aa sakti hain.

Release (Play Store) ke liye

Release build ab bina signing key ke fail hota hai (jaan boojhkar). Testing ke liye debug APK hi use kijiye. Play Store tab dekhenge jab app taiyar ho.
